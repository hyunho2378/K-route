# 시연 시나리오 (1분)

> 목표: 퀴즈 → 추천 → 지도 동선 → 출발 → 챗봇까지 한 흐름으로 보여 준다.
> 준비: 로그인된 계정 1개 · 서버 예열(`/health` 1회) · 챗봇은 배포 서버 env에 `LLM_PROVIDER=gemini`·`GEMINI_API_KEY` 설정(미설정이면 원문 모드로 강등)

## 0. 시작 전 점검 (발표 30분 전)

| # | 확인 | 방법 |
|---|---|---|
| 1 | 서버 깨우기 | 브라우저로 `{배포_URL}/health` → `{"status":"ok"}` |
| 2 | DB 연결 | 같은 주소에 `?deep=1` → `"db":"ok"` |
| 3 | 공사 데이터 | `/gts/build` 카드에 사진과 집중률 Chip이 보이면 정상 |
| 4 | 챗봇 | 서버 env에 `GEMINI_API_KEY`·`LLM_PROVIDER=gemini` 설정 확인 → 질문에 문장으로 답하면 정상. 미설정이면 원문 모드로 나온다(§2 A안) |
| 5 | 스탬프 | `node server/scripts/stamp-tags.js {배포_URL}` 로 URL 뽑아 스티커에 기록 |

> `{배포_URL}` = Cheongchun Line 실배포 주소로 교체. 배포 확정 후 스탬프 태그도 같은 `SESSION_SECRET`으로 재발급한다.

## 1. 본 시연 (60초)

| 초 | 화면 | 말할 것 | 보여 줄 것 |
|---|---|---|---|
| 0~10 | `/gts/quiz` | "춘천의 K-콘텐츠를 취향으로 고릅니다" | 5문항을 탭으로 빠르게 넘긴다. 결과 배지가 찍힌다 |
| 10~25 | `/gts/build` | "한국관광공사 데이터로 채운 추천입니다" | 카드의 K배지와 집중률 Chip. 카드를 열어 공사 원문 상세를 보여 준다 |
| 25~35 | `/gts/route` | "고른 순서가 그대로 동선이 됩니다" | 번호 핀과 선이 그려진다. 타임라인에 배지·혼잡도 |
| 35~45 | `/gts/go` | "현위치에서 첫 장소까지" | 위치 동의 → 도보·택시 예상 → "지금 가면 여유" 카드 |
| 45~60 | 챗봇 | "공사 공식 데이터만 답하는 안내원입니다" | 우하단 버튼 → "막국수 만들기 체험 할 수 있는 곳 있어?" → 답변 + **출처 칩** → 칩을 눌러 상세로 |

### 챗봇에서 보여 줄 질문 3개

1. `막국수 만들기 체험 할 수 있는 곳 있어?` → 춘천막국수체험박물관(공사 상세 원문 근거) + 출처 칩
2. `공지천이 겨울연가 촬영지야?` → **촬영 근거가 없다고 답한다.** 지어내지 않는 것을 보여 주는 질문
3. `부산 해운대 횟집 추천해줘` → **"정보가 없습니다".** 범위 밖이면 모델을 부르지도 않는다

외국어를 보여 줄 때는 언어를 ไทย로 바꾸고 `พิพิธภัณฑ์แอนิเมชันมีอะไรให้ทำบ้าง`(애니메이션박물관에서 뭘 할 수 있나요) 를 묻는다.
공사 데이터에 태국어가 없어도 한국어·영어 원문을 읽고 태국어로 답한다.

## 2. 폴백 경로 (문제가 생기면)

| 상황 | 증상 | 대응 |
|---|---|---|
| A. 생성기 미설정·장애 | 답변이 문장이 아니라 공사 원문 그대로 나오고 "원문 모드" 안내가 붙는다 | 그대로 진행한다. **이게 설계된 무환각 안전 모드다.** "생성기가 없으면 지어내지 않고 공식 원문만 보여 준다"로 설명 |
| B. 공사 API가 느리거나 막힌다 | 카드 이미지·집중률이 비어 보인다 | 화면은 폴백 데이터로 계속 뜬다. 집중률 Chip이 없는 상태로 진행 |
| C. 오디오가이드 한도 초과 | 상세의 해설 블록이 안 보인다 | 블록만 빠지고 나머지는 정상. 한도는 다음 날 풀린다 |
| D. 위치 권한 거부 | `/gts/go` 출발지가 안 잡힌다 | 춘천역으로 자동 대체된다. 그대로 시연 |
| E. 서버 콜드 스타트 | 첫 요청이 30초 이상 걸린다 | 0번 점검을 다시 한다(발표 직전 `/health` 1회) |
| F. 스탬프 태그가 인증되지 않는다 | `/stamp/...` 에서 "태그를 확인하지 못했어요" | 스티커 URL이 **배포 서버와 같은 `SESSION_SECRET`** 으로 뽑혔는지 확인 |

## 3. 하지 말 것

- 공지천을 '겨울연가 촬영지'로 소개하지 않는다. 레고랜드를 K-콘텐츠로 부르지 않는다.
- 춘천 철도는 ITX 청춘과 일반열차다. 다른 열차 이름으로 부르지 않는다.
- 근거가 약한 장소를 성지로 소개하지 않는다. 배지가 붙은 곳만 K-콘텐츠로 말한다.
