# K-가이드 챗봇 골든셋 · 한국어(150)

> 기준 규칙 = `server/services/rag.mjs`의 `RULES`(한국어)·`RULES_EN`(영어·태국어). 답변은 그 규칙을 적용한 모범 응답이다.
> 병렬 골든셋: 같은 150문항을 ko·en·th 세 파일로 나란히 둔다(문항 번호 동일). 키 설정 후 돌려 규칙 준수(무환각·출처·거짓전제 거부·언어 유지)를 PASS/FAIL로 검증한다.
> 사실 근거 = 공사 데이터 + Cheongchun Line 검증(플랜·리서치). 자료에 없는 운영시간·가격·촬영지·연고는 넣지 않는다. 라이브 답변은 `spot_chunks` 근거로 생성되어 세부가 더 풍부할 수 있으며, 아래는 규칙 준수 기준선이다.


## A. 정상 추천·안내 (55)

**A1.** 춘천 오면 뭘 먹어야 해?
```
춘천은 닭갈비와 막국수의 원조 도시라 이 둘은 꼭 드셔보시면 좋아요.
- **춘천 닭갈비**: 명동 닭갈비골목에 가게가 모여 있어 골라 먹는 재미가 있어요.
- **춘천 막국수**: 메밀로 만든 시원한 국수라 닭갈비와 함께 먹기 좋아요.
막국수를 직접 만들어 보고 싶으시면 춘천막국수체험박물관도 있어요.
```

**A2.** 애니메이션박물관은 뭐 하는 곳이야?
```
애니메이션박물관은 국내에 하나뿐인 애니메이션 전문 박물관이에요. 서면에 있고 토이로봇관이 함께 있어 전시와 체험을 같이 즐길 수 있어요. 대중교통으로 가면 배차가 길 수 있으니 시간을 미리 확인해보시는 게 좋아요.
```

**A3.** 겨울연가 관련 장소 가보고 싶어.
```
겨울연가의 배경이 된 곳들을 둘러보실 수 있어요.
- **춘천고**: 드라마 배경으로 알려진 학교예요.
- **중앙시장**: 도심에 있어 걷기 편하고 함께 들르기 좋아요.
- **중도**: 의암호 가운데 섬이라 물가 풍경이 좋아요.
```

```

```

**A5.** 아이랑 갈 만한 실내 장소 추천해줘.
```
아이와 함께라면 비를 피하면서 즐길 실내 장소가 좋아요.
- **애니메이션박물관**: 국내 유일 애니메이션 박물관이라 아이가 좋아할 전시가 많아요.
- **토이로봇관**: 애니메이션박물관과 함께 있어 한 번에 둘러보기 편해요.
이동 배차가 길 수 있으니 출발 전에 시간을 확인해보시면 좋아요.
```

**A6.** 비 오는 날 갈 만한 곳 있어?
```
비 오는 날은 실내에서 즐길 수 있는 곳이 좋아요.
- **애니메이션박물관**: 실내 전시라 날씨와 상관없이 둘러보기 좋아요.
- **춘천막국수체험박물관**: 막국수 만들기 체험을 실내에서 할 수 있어요.
```

**A10.** 자연 풍경 좋은 곳 가고 싶어.

```
청평사는 육로 대중교통이 드물어 뱃길과 시간표를 미리 확인해보시는 게 좋아요.
```

## B. 교통·실현 가능성 (30)

**B1.** 청평사랑 남이섬 하루에 다 갈 수 있어?
```
하루에 두 곳을 대중교통으로 다 도시기는 어려워요. 청평사에서 남이섬까지 대중교통으로 세 시간 안팎이 걸리고, 청평사 쪽은 육로 버스가 하루 두 번뿐이에요. 한 곳을 정해 여유 있게 도시는 걸 추천드려요.
```

**B2.** 애니메이션박물관 가는 버스 자주 있어?
```
애니메이션박물관이 있는 서면행 버스는 시내 진입이 하루 다섯 번 정도예요. 배차가 두세 시간까지 벌어질 수 있어서, 시간표를 미리 확인하고 움직이시는 게 좋아요.
```

**B3.** 외곽 관광지 막차 몇 시야?
```
외곽과 물가 쪽은 막차가 이른 편이에요. 대체로 17:30에서 19:00 사이에 끊겨서, 늦게까지 있으면 도심으로 돌아오기 어려워질 수 있어요. 도심 간선버스는 더 늦게까지 다니니 동선 끝은 도심 쪽으로 잡으시는 게 좋아요.
```

**B4.** 청평사는 어떻게 가?
```
청평사는 소양강댐에서 배를 타고 들어가는 길이 대표적이에요. 육로 버스는 하루 두 번뿐이라, 뱃길 운항 시각과 버스 시간을 함께 확인해두시는 게 좋아요.
```

**B5.** 제이드가든 대중교통으로 갈 수 있어?
```
제이드가든은 대중교통으로 곧장 가기 어려운 곳이에요. 가까운 굴봉산역에서도 4킬로미터쯤 떨어져 있어서, 방문 전에 이동 방법을 미리 확인해두시는 게 좋아요.
```

**B6.** 춘천 시내버스 밤 늦게까지 다녀?
```
노선에 따라 달라요. 도심을 도는 간선버스는 밤까지 다니지만, 외곽 관광지로 가는 지선은 저녁 이르게 끊기는 편이에요. 외곽 일정은 낮에 마치고 도심으로 돌아오시는 걸 추천드려요.
```

**B7.** 춘천까지 무슨 기차로 가?
```
서울에서 춘천까지는 ITX 청춘과 일반열차로 오실 수 있어요. 경춘선을 따라 들어오는 길이라 도심 접근이 편해요.
```

**B8.** 김유정문학촌은 대중교통으로 가기 편해?
```
네, 대중교통 접근이 좋은 편이에요. 경춘선 김유정역에서 가까워 걸어서 닿을 수 있고, 강촌레일파크와 이어 다니기도 좋아요.
```

**B9.** 레고랜드는 어떻게 가?
```
레고랜드는 춘천역에서 버스로 이어져 있어요. 춘천역 방면 노선이 다리를 건너 바로 닿는 편이라 도심에서 접근하기 어렵지 않아요.
```

**B10.** 외곽에서 저녁까지 있으면 뭐가 문제야?
```
외곽은 막차가 이른 게 문제예요. 물가와 외곽은 대체로 17:30에서 19:00 사이에 끊겨서, 저녁까지 있으면 도심으로 돌아오기 어려워질 수 있어요. 저녁은 도심 쪽에서 마무리하시는 게 안전해요.
```

**B11.** 김유정에서 소양강 스카이워크까지 대중교통으로 얼마나 걸려?
```
대중교통으로 한 시간 남짓 걸려요. 자가용보다 세 배 넘게 걸리는 구간이라, 전철과 도심 환승 시간을 넉넉히 잡으시는 게 좋아요.
```

**B12.** 남이섬에서 소양강 스카이워크까지 대중교통 오래 걸려?
```
자가용보다 두 배 반쯤 더 걸리는 구간이에요. 남이섬 쪽은 가평에서 전철과 버스를 갈아타야 해서 이동 시간을 넉넉히 잡으시는 게 좋아요.
```

**B13.** 제이드가든에서 남이섬 이동 편해?
```
대중교통으로는 편하지 않은 구간이에요. 강원과 경기 경계라 농어촌버스로 우회하고 갈아타야 해서, 이동 방법을 미리 확인해두시는 게 좋아요.
```

**B14.** 강촌레일파크에서 청평사 갈 수 있어?


**B15.** 춘천역에서 레고랜드 금방 가?
```
네, 비교적 금방 가는 편이에요. 춘천역 방면 버스가 다리를 건너 바로 닿아서 도심에서 접근하기 편해요.
```

**B16.** 남춘천역에서 김유정문학촌 가기 편해?
```
네, 접근이 좋은 편이에요. 경춘선으로 한 정거장 거리라 대중교통 시간이 잘 맞아요.
```

**B17.** 시티투어버스 어떻게 타?
```
춘천역에서 출발하고, 정해진 시각에 도는 방식이에요. 잔여석 현장 탑승도 되지만 사전 예약을 해두시는 게 안전해요.
```

**B18.** 시티투어버스 월요일에 해?
```
월요일은 정기 휴무예요. 다른 요일에 운행하니 요일을 확인하고 예약해두시는 게 좋아요.
```

**B19.** 청평사 배 언제 끊겨?
```
청평사 뱃길은 오후에 운항이 끝나요. 계절에 따라 종료 시각이 달라서, 돌아오는 배 시각을 방문 전에 꼭 확인해두세요.
```

**B20.** 서면 애니박물관 쪽 막차 이른 편이야?
```
네, 서면 쪽은 막차가 이른 편이에요. 시내 진입 버스가 하루 다섯 번 정도라, 늦지 않게 나오시고 시간표를 미리 확인해두시는 게 좋아요.
```

**B21.** 지금 있는 데서 첫 장소까지 어떻게 가?

```
현재 위치를 켜주시면 첫 장소까지 걸어가는 길과 택시 예상 시간을 안내해드려요. 위치를 허용하고 출발 화면에서 확인해보세요.
```

**B22.** 뚜벅이인데 외곽까지 갈 수 있어?

**B23.** 도심은 밤에도 버스 있어?

```
네, 도심 간선버스는 밤까지 다니는 편이에요. 다만 외곽 지선은 이르게 끊기니 밤 이동은 도심 안에서 하시는 게 좋아요.
```

**B24.** 렌터카 없이 다 돌 수 있을까?

```
도심 안이면 렌터카 없이도 충분히 도실 수 있어요. 다만 외곽 명소는 배차와 막차 제약이 커서, 외곽을 넣으실 거면 시간표를 미리 짜두시는 게 좋아요.
```

**B25.** 소양강댐은 어떻게 가?

```
소양강댐은 도심에서 버스로 이어져 있어요. 도심 방면 노선이 비교적 자주 다녀서 접근이 어렵지 않고, 청평사 뱃길도 이곳에서 이어져요.
```

**B26.** 청평사 육로로도 갈 수 있어?
```
육로 버스가 있긴 하지만 하루 두 번뿐이에요. 정기 일정에 넣기는 어려워서, 대부분 소양강댐에서 배를 타고 들어가요.
```

**B27.** 하루에 두 곳 이상 볼 수 있어?
```
도심끼리 묶으면 두 곳 이상도 충분히 도실 수 있어요. 다만 외곽을 섞으면 이동만 두세 시간이라 한 곳으로 끝나기 쉬우니, 도심 위주로 잡으시는 게 좋아요.
```

**B28.** 막차 놓치면 어떻게 해?
```
외곽에서 막차를 놓치면 택시로 나와야 할 수 있어요. 그래서 외곽은 돌아오는 버스나 배 시각을 미리 확인해두시는 게 좋아요.
```

**B29.** 애니박물관 갔다가 레고랜드 갈 수 있어?
```
이동이 오래 걸려 하루에 붙이기는 빠듯해요. 대중교통으로 한 시간 넘게 걸리는 구간이라, 두 곳을 다 보시려면 아침 일찍 시작하시는 게 좋아요.
```

**B30.** 김유정 갔다가 레고랜드도 볼 수 있어?
```
가능은 하지만 환승에 시간이 꽤 들어요. 김유정에서 남춘천을 거쳐 레고랜드행 버스로 갈아타는 데 대기까지 넉넉히 잡으셔야 해서, 늦지 않게 움직이시는 게 좋아요.
```
