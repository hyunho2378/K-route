# K-가이드 챗봇 골든셋 · ไทย(150)

> 기준 규칙 = `server/services/rag.mjs`의 `RULES`(한국어)·`RULES_EN`(영어·태국어). 답변은 그 규칙을 적용한 모범 응답이다.
> 병렬 골든셋: 같은 150문항을 ko·en·th 세 파일로 나란히 둔다(문항 번호 동일). 키 설정 후 돌려 규칙 준수(무환각·출처·거짓전제 거부·언어 유지)를 PASS/FAIL로 검증한다.
> 사실 근거 = 공사 데이터 + Cheongchun Line 검증(플랜·리서치). 자료에 없는 운영시간·가격·촬영지·연고는 넣지 않는다. 라이브 답변은 `spot_chunks` 근거로 생성되어 세부가 더 풍부할 수 있으며, 아래는 규칙 준수 기준선이다.


## A. 정상 추천·안내 (55)

**A1.** มาชุนช็อนควรกินอะไรดี
```
ชุนช็อนเป็นต้นกำเนิดของทักคาลบีและมักกุกซู ทั้งสองอย่างน่าลองมากค่ะ
- **ทักคาลบีชุนช็อน**: ร้านอยู่รวมกันแถวถนนทักคาลบีเมียงดง เลือกร้านง่ายค่ะ
- **มักกุกซูชุนช็อน**: เส้นบักวีตเย็น ๆ กินคู่กับทักคาลบีเข้ากันดีค่ะ
ถ้าอยากลองทำเองมีพิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อนด้วยค่ะ
```

**A2.** พิพิธภัณฑ์แอนิเมชันเป็นที่แบบไหน
```
พิพิธภัณฑ์แอนิเมชันเป็นพิพิธภัณฑ์แอนิเมชันแห่งเดียวในเกาหลีค่ะ อยู่ที่เขตซอมยอนและมีพิพิธภัณฑ์หุ่นยนต์ของเล่นอยู่ข้าง ๆ จึงชมนิทรรศการและเล่นกิจกรรมได้ในที่เดียว รถเมล์มาไม่บ่อย แนะนำให้เช็กเวลาก่อนไปค่ะ
```

**A3.** อยากไปสถานที่ที่เกี่ยวกับเพลงรักในสายลมหนาว
```
คุณสามารถไปชมสถานที่ที่เป็นฉากของละครเพลงรักในสายลมหนาวได้ค่ะ
- **โรงเรียนมัธยมชุนช็อน**: เป็นฉากที่รู้จักกันในละครค่ะ
- **ตลาดจุงอัง**: อยู่ใจกลางเมือง เดินไปง่ายค่ะ
- **เกาะจุงโด**: เกาะกลางทะเลสาบอึยอัม วิวริมน้ำสวยค่ะ
```

**A4.** มีที่ให้ลองทำมักกุกซูเองไหม
```
ที่พิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อน คุณลองทำมักกุกซูเองได้ค่ะ ไม่ใช่แค่กิน แต่ได้ลงมือทำด้วย จึงเหมาะมากับครอบครัวหรือเพื่อนค่ะ
```

**A5.** แนะนำที่ในร่มสำหรับไปกับเด็กหน่อย
```
ถ้าไปกับเด็ก ที่ในร่มที่หลบฝนได้จะดีค่ะ
- **พิพิธภัณฑ์แอนิเมชัน**: พิพิธภัณฑ์แอนิเมชันแห่งเดียวในเกาหลี มีของให้เด็กชมเยอะค่ะ
- **พิพิธภัณฑ์หุ่นยนต์ของเล่น**: อยู่ติดกัน ชมได้ในรอบเดียวค่ะ
รถเมล์มาไม่บ่อย เช็กเวลาก่อนออกเดินทางนะคะ
```

**A6.** วันฝนตกมีที่ไหนน่าไปบ้าง
```
วันฝนตก ที่ในร่มจะดีที่สุดค่ะ
- **พิพิธภัณฑ์แอนิเมชัน**: นิทรรศการในร่ม ชมได้ทุกสภาพอากาศค่ะ
- **พิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อน**: ทำมักกุกซูในร่มได้ค่ะ
```

**A7.** โซยังกังสกายวอล์กเป็นยังไงบ้าง
```
โซยังกังสกายวอล์กเป็นจุดชมวิวทะเลสาบกลางเมือง เดินเหมือนอยู่บนผิวน้ำค่ะ อยู่ใกล้สถานีชุนช็อน ต่อกับแผนอื่นได้ง่ายค่ะ
```

**A8.** ที่ไหนเหมาะสำหรับคู่รัก
```
ขอแนะนำเส้นทางริมน้ำที่เดินด้วยกันได้ดีค่ะ
- **โซยังกังสกายวอล์ก**: จุดชมวิวบนผิวน้ำ เดินเล่นด้วยกันดีค่ะ
- **เกาะจุงโด**: เกาะกลางทะเลสาบอึยอัม เดินชมวิวทะเลสาบได้ค่ะ
```

**A9.** เล่าเรื่องหมู่บ้านวรรณกรรมคิมยูจองหน่อย
```
หมู่บ้านวรรณกรรมคิมยูจองเป็นพื้นที่จัดแสดงวรรณกรรมในหมู่บ้านซิลเล เขตซินดงค่ะ อยู่ใกล้สถานีคิมยูจองสายคยองชุน ไปด้วยรถสาธารณะสะดวก และเที่ยวต่อกับคังชนเรลพาร์คได้ค่ะ
```

**A10.** อยากไปที่ที่วิวธรรมชาติสวย
```
ขอแนะนำที่ที่มีวิวทะเลสาบและริมน้ำค่ะ
- **วัดชองพยองซา**: วัดที่ไปโดยเรือข้ามทะเลสาบโซยัง มีทั้งน้ำและภูเขาค่ะ
- **เกาะจุงโด**: เกาะกลางทะเลสาบอึยอัม รอบตัวเป็นน้ำค่ะ
รถทางบกไปชองพยองซามีน้อย เช็กเวลาเรือและรถก่อนนะคะ
```

**A11.** อยากไปคาเฟ่ แนะนำหน่อย
```
มีถนนที่คาเฟ่วิวสวยมารวมกันค่ะ
- **ถนนคาเฟ่คูบงซัน**: คาเฟ่รวมกันในเขตทงมยอน วิวเปิดโล่ง เลือกง่ายค่ะ
ถ้าบอกสไตล์ที่ชอบ จะช่วยแคบลงให้อีกได้ค่ะ
```

**A12.** มีเวลาแค่ครึ่งวัน ควรไปไหนดี
```
ถ้ามีครึ่งวัน ควรรวมที่เที่ยวในใจกลางเมืองที่เดินทางสั้นค่ะ
- **โซยังกังสกายวอล์ก**: ใกล้สถานีชุนช็อน แวะสั้น ๆ ได้ค่ะ
- **ถนนทักคาลบีเมียงดง**: อยู่ใจกลางเมือง ต่อกับสกายวอล์กได้ค่ะ
นอกเมืองรถห่าง ครึ่งวันมักได้ที่เดียว จึงแนะนำรวมที่ในเมืองค่ะ
```

**A13.** ช่วยจัดทริปหนึ่งวันให้หน่อย
```
ขอเสนอทริปหนึ่งวันที่เดินทางน้อยค่ะ
1. **พิพิธภัณฑ์แอนิเมชัน**: เริ่มช่วงเช้าด้วยนิทรรศการในร่มค่ะ
2. **ถนนทักคาลบีเมียงดง**: กลับเข้าเมืองมากินมื้อกลางวันค่ะ
3. **โซยังกังสกายวอล์ก**: ช่วงบ่ายเดินริมน้ำค่ะ
รถนอกเมืองห่าง สลับลำดับอาจทำให้เดินทางนานขึ้นค่ะ
```

**A14.** เดินเที่ยว มีที่ไหนไปได้บ้าง
```
ถ้าเดินเที่ยวไม่มีรถ อยู่ในใจกลางเมืองสะดวกที่สุดค่ะ
- **ตลาดจุงอัง**: อยู่ในเมือง เดินถึง และเป็นฉากเพลงรักในสายลมหนาวด้วยค่ะ
- **ถนนทักคาลบีเมียงดง**: อยู่ใกล้ตลาด เดินต่อได้ค่ะ
- **โซยังกังสกายวอล์ก**: จุดริมน้ำที่เดินจากสถานีชุนช็อนได้ค่ะ
```

**A15.** กำลังคิดจะไปเกาะนามี เป็นยังไงบ้าง
```
เกาะนามีมีคนไปมากที่สุด แต่ท่าเรืออยู่ฝั่งคาพยองค่ะ รถสาธารณะจากใจกลางชุนช็อนเชื่อมไม่ค่อยดี ถ้าไปแค่เกาะนามีอาจพลาดตัวเมืองชุนช็อน วางเส้นทางล่วงหน้าถ้าอยากเที่ยวคู่กับในเมืองค่ะ
```

**A16.** จุด K-content ในชุนช็อนอยู่ที่ไหนบ้าง
```
ชุนช็อนมี K-content หลายแขนงค่ะ
- **ฉากเพลงรักในสายลมหนาว**: โรงเรียนมัธยมชุนช็อน ตลาดจุงอัง และเกาะจุงโด เป็นฉากละครที่รู้จักกันค่ะ
- **ทักคาลบีและมักกุกซู**: ต้นกำเนิด K-food ที่คนทั่วโลกตามหาค่ะ
- **พิพิธภัณฑ์แอนิเมชัน**: พิพิธภัณฑ์แอนิเมชันแห่งเดียวในเกาหลีค่ะ
```

**A17.** บอกจุดถ่ายรูปสวย ๆ หน่อย
```
ขอแนะนำจุดริมน้ำสำหรับถ่ายรูปค่ะ
- **โซยังกังสกายวอล์ก**: เก็บภาพเมืองและทะเลสาบพร้อมกันจากบนผิวน้ำได้ค่ะ
- **เกาะจุงโด**: อยู่กลางทะเลสาบอึยอัม รอบตัวเป็นน้ำค่ะ
```

**A18.** อยากทำกิจกรรมกับเพื่อน
```
ถ้าอยากได้กิจกรรมออกแรง เรลไบค์เป็นตัวเลือกที่ดีค่ะ
- **คังชนเรลพาร์ค**: เรลไบค์ที่ปั่นไปตามทางรถไฟเก่าค่ะ
- **หมู่บ้านวรรณกรรมคิมยูจอง**: อยู่ใกล้สถานีคิมยูจอง จับคู่กับเรลพาร์คได้ค่ะ

```
ตลาดจุงอังเป็นตลาดดั้งเดิมในใจกลางชุนช็อนค่ะ เป็นฉากเพลงรักในสายลมหนาวด้วย และอยู่ในเมืองจึงเดินต่อไปที่อื่นได้สะดวกค่ะ

**A20.** คังชนเรลพาร์คคืออะไร
```
คังชนเรลพาร์คคือเรลไบค์ที่ปั่นไปตามทางรถไฟเก่าค่ะ อยู่ใกล้ย่านคิมยูจองสายคยองชุน จึงเที่ยวคู่กับหมู่บ้านวรรณกรรมได้ดีค่ะ

**A21.** มีที่ที่พาพ่อแม่ไปสะดวกไหม
```
ในเมืองที่เดินทางน้อยและเดินง่ายจะดีค่ะ
- **โซยังกังสกายวอล์ก**: ใกล้สถานีชุนช็อน ไปสบาย ๆ ได้ค่ะ
- **ตลาดจุงอัง**: อยู่ในเมือง เดินชมช้า ๆ สะดวกค่ะ
```

**A22.** มีที่เดินเงียบ ๆ คนเดียวไหม
```
ขอแนะนำเส้นทางริมน้ำเงียบ ๆ สำหรับเดินค่ะ
- **เกาะจุงโด**: เกาะกลางทะเลสาบอึยอัม เดินเงียบ ๆ ได้ค่ะ
- **โซยังกังสกายวอล์ก**: จุดชมวิวบนผิวน้ำ เดินเล่นดีค่ะ

```
วันร้อน ในร่มหรือริมน้ำดีที่สุดค่ะ

- **โซยังกังสกายวอล์ก**: อยู่ริมน้ำ ลมเย็นค่ะ

**A24.** มีที่เดินเล่นตอนเช้ามืดไหม
```
เดินเล่นเช้า ริมน้ำในเมืองดีค่ะ **โซยังกังสกายวอล์ก** ใกล้สถานีชุนช็อน เดินเบา ๆ ตอนเช้าได้ค่ะ เช็กเวลาทำการก่อนไปนะคะ

**A25.** แนะนำที่ไปตอนเย็นหน่อย
```
ตอนเย็นในเมืองไม่ต้องห่วงรถเที่ยวสุดท้ายค่ะ กินมื้อเย็นที่ **ถนนทักคาลบีเมียงดง** แล้วเดินในเมืองสบาย ๆ นอกเมืองรถหมดเร็ว ตอนเย็นจึงควรอยู่ในเมืองค่ะ
```

**A26.** มีที่เที่ยวฟรี ๆ ไหม
```
เส้นทางในเมืองที่เดินเล่นก็สนุกจะดีค่ะ
- **ตลาดจุงอัง**: แค่เดินดูก็เพลิน และเป็นฉากเพลงรักในสายลมหนาวค่ะ
- **ถนนทักคาลบีเมียงดง**: อยู่ใกล้ตลาด เดินต่อได้ค่ะ
```

**A27.** ชอบวรรณกรรม มีที่ไหนแนะนำไหม
```
ถ้าชอบวรรณกรรม **หมู่บ้านวรรณกรรมคิมยูจอง** เหมาะมากค่ะ เป็นพื้นที่จัดแสดงวรรณกรรมในหมู่บ้านซิลเล อยู่ใกล้สถานีคิมยูจองค่ะ
```

**A28.** ชอบแอนิเมชัน มีที่ไหนไปได้
```
ถ้าชอบแอนิเมชัน มีที่เหมาะมากค่ะ
- **พิพิธภัณฑ์แอนิเมชัน**: พิพิธภัณฑ์แอนิเมชันแห่งเดียวในเกาหลีค่ะ
- **พิพิธภัณฑ์หุ่นยนต์ของเล่น**: อยู่ติดกัน ชมด้วยกันได้ค่ะ

**A29.** มีที่พักผ่อนริมทะเลสาบไหม
```
มีที่พักผ่อนริมทะเลสาบค่ะ
- **เกาะจุงโด**: เกาะกลางทะเลสาบอึยอัม รอบตัวเป็นน้ำค่ะ
- **โซยังกังสกายวอล์ก**: มองทะเลสาบจากบนผิวน้ำได้ค่ะ

**A30.** อยากเดินตลาด
```
**ตลาดจุงอัง** ดีค่ะ เป็นตลาดดั้งเดิมใจกลางชุนช็อน เดินถึงง่าย และเป็นฉากเพลงรักในสายลมหนาวด้วยค่ะ

**A31.** อยากลองเรลไบค์
```
ลองเรลไบค์ได้ที่ **คังชนเรลพาร์ค** ค่ะ ปั่นไปตามทางรถไฟเก่า และอยู่ใกล้ย่านคิมยูจอง เที่ยวคู่กันได้ค่ะ

**A32.** กินทักคาลบีที่ไหนดี
```
ร้านทักคาลบีอยู่รวมกันที่ **ถนนทักคาลบีเมียงดง** ค่ะ เลือกได้หลายร้านในที่เดียว สะดวกสำหรับคนมาครั้งแรกค่ะ
```

**A33.** มักกุกซูอร่อยที่ไหน
```
มักกุกซูเที่ยวได้แบบนี้ค่ะ
- **ถนนมักกุกซูแซมบัท**: ร้านมักกุกซูรวมกันที่เขตซินบุกค่ะ
- **พิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อน**: ลองทำเองแล้วกินได้ค่ะ

**A34.** คาเฟ่วิวสวยอยู่ที่ไหน

**ถนนคาเฟ่คูบงซัน** ดีค่ะ คาเฟ่วิวเปิดโล่งรวมกันที่เขตทงมยอน เลือกง่ายค่ะ

ถ้าไปกับเด็ก **พิพิธภัณฑ์แอนิเมชัน** ดีที่สุดค่ะ มีทั้งของชมและกิจกรรม เด็กไม่เบื่อค่ะ
```

**E2.** [ก่อนหน้า: ของกิน/ที่เที่ยว/กิจกรรม] เลือกอย่างละหนึ่ง
```
- **ทักคาลบีชุนช็อน**: ของกินเด่นที่ถนนทักคาลบีเมียงดงค่ะ
- **โซยังกังสกายวอล์ก**: ที่เที่ยวเด่นใกล้ในเมืองค่ะ
- **พิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อน**: กิจกรรมทำมักกุกซูค่ะ
```

**E3.** [ก่อนหน้า: พิพิธภัณฑ์แอนิเมชัน] ไปยังไง
```
รถไปเขตซอมยอนที่มีพิพิธภัณฑ์แอนิเมชันมีราววันละห้ารอบ ช่วงห่างนานค่ะ เช็กเวลาก่อนออกเดินทางนะคะ
```

**E4.** [ก่อนหน้า: ทริปหนึ่งวัน] อยู่จนเย็นมีปัญหาไหม
```
ยิ่งออกนอกเมือง รถเที่ยวสุดท้ายยิ่งเร็วค่ะ ริมน้ำและนอกเมืองส่วนใหญ่หยุด 17:30 ถึง 19:00 จบช่วงเย็นในเมืองปลอดภัยกว่าค่ะ
```

**E5.** [ก่อนหน้า: วิธีไปชองพยองซา] ต้องออกก่อนกี่โมง
```
แถวชองพยองซาเรือและรถทางบกเที่ยวสุดท้ายเร็วค่ะ ควรออกแต่เนิ่น ๆ เช็กเวลาเรือและรถขากลับล่วงหน้าจะปลอดภัยค่ะ
```

**E6.** [ก่อนหน้า: ที่ยอดนิยม] มีที่เงียบกว่าไหม
```
ถ้าอยากได้ที่เงียบกว่าที่คนแน่น ที่เที่ยวในตัวเมืองด้านในดีค่ะ แทนเกาะนามีที่คนเยอะ ลองจุดในแผ่นดินจะได้ชมสบาย ๆ ค่ะ
```

**E7.** [ก่อนหน้า: 3 ที่] ที่ไหนใกล้สุด
```
ที่ใกล้ใจกลางเมืองสุดคือ **โซยังกังสกายวอล์ก** ค่ะ ใกล้สถานีชุนช็อน เดินทางสบายค่ะ
```

**E8.** [ก่อนหน้า: ทริปหนึ่งวัน] สลับลำดับได้ไหม
```
สลับได้ค่ะ แต่ลำดับนี้ดีกว่าเมื่อคิดถึงรถเที่ยวสุดท้าย ถ้าเอานอกเมืองหรือริมน้ำไว้ตอนเย็นอาจกลับยากค่ะ
```

**E9.** [ก่อนหน้า: สองที่] สองที่นี้ที่ไหนดีกว่า
```
ที่ไหนดีกว่าขึ้นกับสถานการณ์ค่ะ ถ้าอยากเดินทางน้อย เลือกที่ใกล้ในเมือง ถ้าอยากได้ธรรมชาติ เลือกฝั่งริมน้ำค่ะ
```

**E10.** [ก่อนหน้า: พิพิธภัณฑ์แอนิเมชัน] เป็นในร่มไหม
```
ใช่ค่ะ พิพิธภัณฑ์แอนิเมชันเป็นนิทรรศการในร่ม ชมได้ทุกสภาพอากาศค่ะ
```

**E11.** [ก่อนหน้า: ทักคาลบี/มักกุกซู ภาษาเกาหลี] บอกอันเมื่อกี้เป็นภาษาอังกฤษ
```
Chuncheon is the home of dakgalbi and makguksu.
- **Chuncheon Dakgalbi**: Restaurants cluster on the Myeongdong dakgalbi street.
- **Chuncheon Makguksu**: A cold buckwheat noodle that pairs well with it.
```

**E12.** [ก่อนหน้า: ทริป] มีวิธีที่ถูกกว่าไหม
```
ค่าใช้จ่ายที่แน่นอนยืนยันจากข้อมูลไม่ได้ค่ะ แต่ทริปในเมืองที่เดินได้ประหยัดค่าเดินทาง รวมที่เดินได้อย่างตลาดจุงอังและเมียงดงจะเบากว่าค่ะ
```

**E13.** [ก่อนหน้า: การเดินทาง] นั่งแท็กซี่เท่าไหร่
```
ค่าแท็กซี่ยืนยันจากข้อมูลไม่ได้ค่ะ คร่าว ๆ ยิ่งไกลยิ่งแพง เผื่อประเมินไว้ก่อนสำหรับนอกเมืองนะคะ
```

**E14.** [ก่อนหน้า: ทริปแอ็กทีฟ] พาเด็กเล็กไปได้ไหม
```
ถ้าพาเด็กเล็ก เปลี่ยนเป็นที่ในร่มและเดินทางสั้นดีกว่าค่ะ **พิพิธภัณฑ์แอนิเมชัน** และ **พิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อน** อยู่ในร่ม พาเด็กสะดวกค่ะ
```

**E15.** [ก่อนหน้า: คำแนะนำ] มีที่อื่นอีกไหม
```
มีอีกค่ะ นอกจากที่บอกไป **หมู่บ้านวรรณกรรมคิมยูจอง** และ **คังชนเรลพาร์ค** ก็เที่ยวคู่กันดีค่ะ
```

**E16.** [ก่อนหน้า: ทริปหนึ่งวัน] งั้นเริ่มจากที่แรกเลย
```
ได้ค่ะ ที่แรกคือ **พิพิธภัณฑ์แอนิเมชัน** เริ่มด้วยนิทรรศการในร่มตอนเช้าจะเปิดวันแบบสบาย ๆ ค่ะ
```

**E17.** [ก่อนหน้า: สองที่] แต่ละที่ดียังไง
```
- **โซยังกังสกายวอล์ก**: ใกล้ในเมือง เดินทางสะดวก วิวริมน้ำสวยค่ะ
- **เกาะจุงโด**: เกาะกลางทะเลสาบอึยอัม เดินเล่นเงียบ ๆ ดีค่ะ
```

**E18.** [ก่อนหน้า: ทริปกลางแจ้ง] ถ้าฝนตกไปไหน
```
ถ้าฝนตก เปลี่ยนเป็นในร่มดีกว่าค่ะ **พิพิธภัณฑ์แอนิเมชัน** และ **พิพิธภัณฑ์ประสบการณ์มักกุกซูชุนช็อน** อยู่ในร่ม เที่ยวได้ทุกสภาพอากาศค่ะ
```

**E19.** [ก่อนหน้า: สกายวอล์ก] ไปกี่โมงดี
```
เช็กเวลาทำการที่แน่นอนก่อนไปนะคะ อยู่ในเมืองไปง่าย ช่วงกลางวันที่คนน้อยจะชมได้สบายค่ะ
```

**E20.** [ก่อนหน้า: สกายวอล์ก] แถวนั้นมีที่กินไหม
```
ถ้ากินแถวในเมืองใกล้ ๆ **ถนนทักคาลบีเมียงดง** ดีค่ะ ต่อจากสกายวอล์กเข้าเมือง เดินทางสั้นค่ะ
```

**E21.** [ก่อนหน้า: ทริปหนึ่งวัน] ใช้เวลานานแค่ไหน
```
เวลาที่แน่นอนขึ้นกับการเดินทางและเวลาที่อยู่ค่ะ รวมที่ในเมืองทำให้เดินทางสั้น เที่ยวสามที่ในวันเดียวได้สบายค่ะ
```

**E22.** [ก่อนหน้า: ภาษาอังกฤษ] บอกเป็นภาษาไทย
```
ชุนช็อนเป็นต้นกำเนิดของทักคาลบีและมักกุกซูค่ะ
- **ทักคาลบีชุนช็อน**: ร้านอยู่รวมกันแถวถนนทักคาลบีเมียงดงค่ะ
- **มักกุกซูชุนช็อน**: เส้นบักวีตเย็น ๆ กินคู่กันเข้ากันดีค่ะ
```

**E23.** [ก่อนหน้า: หลายที่] ที่ไหนถ่ายรูปสวยสุด
```
ริมน้ำถ่ายรูปสวยค่ะ ในนั้น **โซยังกังสกายวอล์ก** เก็บเมืองและทะเลสาบในภาพเดียวจากบนผิวน้ำได้ค่ะ
```

**E24.** [ก่อนหน้า: หลายที่] เอาที่เดียวพอ
```
ถ้าเอาที่เดียว แนะนำ **โซยังกังสกายวอล์ก** ค่ะ ใกล้ในเมือง แวะสั้น ๆ ก็ได้ค่ะ
```

**E25.** [ก่อนหน้า: นอกเมือง] อยู่จนเย็นได้ไหม
```
อยู่นอกเมืองจนเย็นอาจกลับยากค่ะ รถเที่ยวสุดท้ายส่วนใหญ่หยุด 17:30 ถึง 19:00 ออกเข้าเมืองก่อนเย็นจะปลอดภัยค่ะ
```
