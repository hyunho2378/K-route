# docs/kto · 한국관광공사 OpenAPI 활용가이드 배치 폴더

KTO_API.md "docs/kto/ 배치 목록"에 따라 아래 1~6 서비스의 '오픈API 활용가이드' 문서(PDF/DOCX)를 이 폴더에 넣는다. 파일명에 서비스명 포함.
공사 API의 엔드포인트·오퍼레이션명·파라미터는 이 폴더 문서에 적힌 것만 사실로 쓴다(PITFALLS.md · 문서 없이 지어내기 금지).

1. 국문 관광정보 서비스(지역기반 목록·상세)
2. 다국어 관광정보 서비스(영어 최소 · 일/중 여유되면)
3. 관광지별 연관 관광지 정보
4. 관광지 집중률·방문자 추이 예측
5. 관광지 오디오가이드(odii)
6. (선택) 관광사진 정보

현재 상태(2026-09-11 · P0 SETUP): 활용가이드 문서 0건 · 공사 키 미발급(server/.env에 없음).
